# Leave Management System

A full-stack web application for managing employee leave requests, balances, approvals, policies, notifications and reports.

## Project Objectives

- Allow employees to submit and track leave requests online.
- Provide employees with accurate leave balance information.
- Help managers review requests and identify overlapping team absences.
- Give HR officers tools to manage employees, leave policies and public holidays.
- Maintain secure and auditable records of leave requests and approval decisions.
- Demonstrate professional full-stack development, testing and deployment practices.

## Planned Technology Stack

- React
- TypeScript
- Vite
- Node.js
- Express
- PostgreSQL
- Prisma
- GitHub Actions

## Project Structure

- `apps/web` - React frontend
- `apps/api` - Express backend
- `packages/shared` - Shared types and validation
- `prisma` - Database schema and migrations
- `docs` - Project documentation
- `tests` - End-to-end tests
